# Sophia Hudelist

## Speech & Language Data Processing | NLP Research & Prototyping

I help turn language data into useful insights and practical tools. With a First-Class BSc in Linguistics from the University of York, I combine linguistic expertise with data analysis, Python development, and applied AI research.

My work spans linguistic data processing, corpus analysis, and the evaluation of language technologies, with a particular interest in speech technology and language-focused AI applications.

## What I can help with

- **Linguistic Data Processing & Automation:** Building Python workflows to clean, process, organize, and analyze text data. I work with tools such as pandas and spaCy to automate repetitive tasks and make linguistic datasets easier to work with.
- **Corpus Analysis & Data Visualization:** Working with linguistic corpora and tools such as KorAP and COSMAS II to investigate language patterns. I also develop KorAP API scripts and create data visualizations using R, JavaScript, and GeoJSON.
- **AI Research & Prototype Evaluation:** Reviewing relevant research, testing AI and speech-technology prototypes, identifying limitations, and analyzing qualitative and quantitative findings to support informed development decisions.
